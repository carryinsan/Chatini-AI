1) Scope

Use only on an application you own or are explicitly authorized to test. This page intentionally avoids brute-force, destructive, persistence, data deletion, credential guessing, and arbitrary third-party scanning.
These are paths only. The tool will normalize them to the current origin and will reject off-origin URLs.

2) What this can actually test from a browser

✓ Same-origin HTTP behavior
✓ Security response headers visible to JavaScript
✓ HTTPS / mixed-content indicators
✓ Cookie flags that are visible to the browser
✓ CORS observations for requests the browser permits
✓ Basic method/endpoint behavior using harmless requests
✓ Error leakage in response bodies/statuses
✓ robots.txt / sitemap / security.txt exposure
✓ Basic XSS sink indicators in the current DOM
✓ Client-side storage exposure
✓ Dangerous URL / form / script references in the current page
✓ Basic cache/security-policy observations
The browser cannot reliably prove server-side SQL injection, SSRF, authorization correctness, cloud IAM, database isolation, secret rotation, or backend code flaws. Those require server-side testing/logs or an authorized scanner.
