Fuzzing Dictionary Info

The scanner uses controlled, non-executing markers and response observations. It checks for:
  • SQLi: Syntax errors, DB-specific tracebacks (MySQL, Postgres, Oracle, SQLite).
  • XSS: Exact DOM reflection of unencoded payload markers.
  • LFI/RCE: Linux root signatures, Windows boot loader strings, Python stack traces.
  • Header Injection: Host overrides, X-Forwarded-For admin bypass attempts.
