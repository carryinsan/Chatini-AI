What this tool can and cannot prove

Can test actively:
same-origin status/method behavior; headers; CORS observations; safe reflection probes; error disclosure; path normalization differences; cache headers; DOM sinks; browser storage; local source files; endpoint surface.
Cannot prove from this page alone:
SQL injection exploitability; server-side SSRF; database isolation; cloud IAM; authorization correctness across accounts; secret rotation; backend RCE; server-side rate-limit correctness; hidden routes not discoverable from your supplied sources.

Machine-readable report

Safety model: manual start; same-origin scope; bounded concurrency; timeout; no credential guessing; no destructive verbs by default; no automatic uploads; no automatic external scanning. A PASS means no issue was confirmed by this browser-side test, not that the backend is vulnerability-free.
