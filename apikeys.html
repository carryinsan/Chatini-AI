1. AI Chat & Logic

Endpoint: POST /api/chat

Spark 100 calls/day. Ultra-fast text logic.
Flux 20 calls/day. Balanced coding & logic.
Oracle 5 calls/day. Deep logic + Tavily Web Search. 
const response = await fetch('https://chatini-ai.vercel.app/api/chat', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer Lexis-YOUR_API_KEY', // <-- Very Important!
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    modelId: "oracle", // spark, flux, or oracle
    messages: [{ role: "user", content: "Analyze the latest AI news." }]
  })
});
