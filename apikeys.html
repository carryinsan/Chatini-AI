LexisAI provides enterprise endpoints. Your endpoint base URL is https://chatini-ai.vercel.app (or https://lexis-ai-chatini.vercel.app). You must include your API key in the Authorization header for every request.

1. Standard Chat (Text)

Endpoint: POST /api/chat. Select your model: spark, flux, or oracle. (Oracle automatically includes real-time Tavily Web Search).

const response = await fetch('https://chatini-ai.vercel.app/api/chat', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer Lexis-YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    modelId: "oracle", // Options: 'spark', 'flux', 'oracle'
    messages: [
      { role: "user", content: "What is the latest news today?" }
    ]
  })
});
const data = await response.json(); // Read the stream or JSON response

2. Image Generation

Endpoint: POST /api/image. Supports modifiers like --ar 16:9 and --style cinematic.

const response = await fetch('https://chatini-ai.vercel.app/api/image', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer Lexis-YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    prompt: "/imagine A futuristic cyberpunk city --ar 16:9 --style cyberpunk"
  })
});

3. Advanced Feature Endpoints

Send a simple prompt to these endpoints, and they return compiled JSON payloads (or HTML for Apps) that you can render in your own UI.

  • Maths & Graphing (POST /api/maths) Body: { "query": "Graph the trajectory of a rocket" }

  • Slide Deck Generation (POST /api/presentation) Body: { "topic": "Q3 Financial Report for Tesla" }
  • Deep Research (POST /api/research) Body: { "query": "Comprehensive analysis of quantum computing" }
