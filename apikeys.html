Part 2: The 7 Feature Endpoints

LexisAI offers 7 completely distinct endpoints. Every request to any endpoint requires the Authorization: Bearer Lexis-... header.

1. General Intelligence Stream POST /api/chat

Streams standard SSE text responses. Requires a message array and a modelId.

const res = await fetch('https://chatini-ai.vercel.app/api/chat', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer Lexis-YOUR_KEY', 'Content-Type': 'application/json' },
  body: JSON.stringify({
    modelId: "oracle", 
    messages: [{ role: "user", content: "Who won the superbowl yesterday?" }]
  })
});
2. High-Res Image Generation POST /api/image

Generates images using Gemini 2.5 Flash Image. Supports modifiers: --ar 16:9, --style cinematic, --style anime, --style 3d.

const res = await fetch('https://chatini-ai.vercel.app/api/image', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer Lexis-YOUR_KEY', 'Content-Type': 'application/json' },
  body: JSON.stringify({ prompt: "A cyberpunk city in the rain --ar 16:9 --style cinematic" })
});
3. Cartesian Math Engine POST /api/maths

Returns a compiled JSON payload containing axis ranges, parametric coordinates, and expressions for you to plot on an HTML Canvas.

// Body Payload
{ "query": "Graph the trajectory of a rocket launch with wind resistance" }
4. Web App Builder POST /api/app-builder

Generates a massive, single-file HTML/CSS/JS web application based on the user's prompt using Tailwind.

// Body Payload
{ "prompt": "Create a fully functional Pomodoro timer with a dark mode toggle" }
5. Slide Deck Generator POST /api/presentation

Returns a JSON schema containing slides, titles, bullet points, and AI-selected imagery layouts ready to be converted into .PPTX.

// Body Payload
{ "topic": "Q3 Financial Earnings Report for Tesla" }
6. Deep Auto-Pilot Research POST /api/research

Triggers an autonomous agent that scrapes the web, compiles massive data, and returns a hyper-condensed research JSON context.

// Body Payload
{ "query": "Comprehensive analysis of quantum computing advancements in 2026" }
7. Study Deck / Flashcards POST /api/study-deck
