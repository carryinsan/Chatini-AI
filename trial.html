One‑Commit Publisher

Replace a repository’s files from one ZIP or folder and publish the complete replacement as one Git commit. ZIP validation runs locally first; GitHub access is tested separately. No local Git installation required.

1 · Connect your repository

You can paste owner/repo or the full GitHub repository URL.
Create a token restricted to this repository with Contents: Read and write. Add Workflows: Read and write when replacing .github/workflows.
Privacy: the token is kept only in this page’s memory and is sent directly to api.github.com. It is not saved in local storage, cookies, or a server. Close the page to clear it.

Uses GitHub’s Git Database API. Every uploaded file’s content (including binary files) becomes a Git blob; a clean tree is created without the old base tree; the new tree is checked path-by-path and by blob SHA; then exactly one commit is made and the branch is updated without force. A concurrent push or branch-protection rule stops the update safely.
